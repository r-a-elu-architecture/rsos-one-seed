# SEC1 v2 build 1: the turquoise organism over supply + drift (under TOP_MAP_SEC1_v2.md)

Sealed before the run. Fresh seeds 7200-7215 x density 1..5 (80 organisms). N = 40 units per host, T = 120 ticks,
budget 2 landings per host per tick (4 shared in the organism). Hosts coupled in the world for every policy.
Predictions (one-sided sign tests over 80 organisms, p < 0.05; Holm across hosts when combined):
P0 organism dragon beats unhealed (report+popular); P1 one landing on the lowest-reserve unit changes more units with
spheres and tubes on than off (20 ticks); P2 organism beats a global change of the same size; P3 Spearman(d, organism
gain over unhealed) > 0; P5 organism beats the best of three native pairs; P7 organism beats the same hosts run apart
(each with its own dragon, own-host scoring, the same total budget).
Disclosures: smoke on seed 999 (outside the test) set the budget to 2 per host and the P1 landing to the lowest-reserve
unit, because at 4 per host every policy scored >= 0.98. On that smoke seed apart beat organism at d=1 and d=5
(0.868 vs 0.850, 0.990 vs 0.987); the organism algorithm was not changed after seeing this. Evolutionary perspective and
P6 are built in the discovery host, not here. P4: the protocol host's v1 result is unaffected by this build.
