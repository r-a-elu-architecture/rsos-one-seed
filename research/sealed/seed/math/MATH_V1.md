# The mathematics of the seed, version 1 (20 Nov 2026, ~07:15 Vilnius)

Private. Written before SPHERE1 (its predictions use §4–§6). Seed: `../SEED_V3.md`. Layer 2.

## 1. Objects

- **Space.** X: a set of positions with a nesting order ⊑ (a part inside a whole) and a zoom map z: X → X that sends
  a position to the whole that contains it.
- **Component.** c = (id, φ, s, ℓ, P, x): identity, fingerprint φ ∈ {−1, +1}^D (the carrier, "light"), state s ∈ S_c
  (its safe range is S_c), level ℓ, ports P, position x ∈ X.
- **World.** W: a finite map from components to states, W(c) ∈ S_c. 𝒲 = the set of worlds.
- **Operator.** o = (R_o, W_o, f_o) with read set R_o, write set W_o and f_o: S^{R_o} → S^{W_o}. Applying o to W
  gives o(W), equal to W outside W_o.
- **Host.** H = (E_H, O_H, D_H): an executor, the operators it allows and a damage process. Executing o on H yields
  o(W) with probability 1 − p_H(o, W), otherwise a world that differs from o(W) (a failure).
- **Mirror.** M: a reading map from a stored carrier and a damage pattern to an estimate Ŵ.

## 2. The algebra

Operators compose: (o₂ ∘ o₁)(W) = o₂(o₁(W)); R_{o₂∘o₁} ⊆ R_{o₁} ∪ (R_{o₂} \ W_{o₁}) ∪ …, W_{o₂∘o₁} = W_{o₁} ∪ W_{o₂}.
Two operators **commute** when W_{o₁} ∩ (R_{o₂} ∪ W_{o₂}) = ∅ and W_{o₂} ∩ R_{o₁} = ∅; commuting operators run in
parallel without conflict ("in unison"). **Nesting**: an operator on a whole is lifted from operators on its parts by
zoom, o^z(W) = z∘o∘z⁻¹. **Re-hosting**: the same o, a different H.

## 3. Law 0 as an invariant

A run is admissible if every intermediate world satisfies W(c) ∈ S_c for all c, every write stays within budget, and
every received message verifies (READY). **The monitor** is a predicate m on (W, action); an action takes effect only
if m holds. Law 0 holds for a run iff every effect passed m. (Executed: OPS1 Z1/Z2.)

## 4. Law 1′, the compounding bound (theorem)

Let an operation need n elements, and let A_i be the event "element i is read correctly", P(A_i) = 1 − ε_i.

**Theorem 1.** If the events A_1, …, A_n are positively associated (for any two increasing functions f, g of the
indicators, Cov(f, g) ≥ 0), then

  P(operation fails) = 1 − P(∩ A_i) ≤ 1 − ∏ (1 − ε_i).

*Proof.* Indicators of positively associated events satisfy P(∩A_i) ≥ ∏P(A_i) (Harris–FKG inequality, by induction
on n with f = 1_{A_1∩…∩A_{k}}, g = 1_{A_{k+1}}). ∎

Equality holds for independent errors (the memory host: 58.66 % against 58.64 %). Clustered errors (bursts, outages,
locks) are positively associated, so they fall below the bound (network, ledger, LLM agents, SQLite).

**Corollary (where the bound fails).** If the successes are **negatively** associated (one element's success makes
another's less likely, e.g. elements competing for a finite pool of slots), P(∩A_i) < ∏P(A_i) is possible, and the
failure rate can **exceed** the compounding bound. *This is a prediction of the theorem:* SPHERE1 includes such a node.

## 5. Law 1 (read scope) and the error-events law

Let the errors of a host be generated by K independent error events per unit of the operation's extent (elements for
element-class hosts, time windows for time-class hosts). An operation spanning extent n meets **n_eff = number of
independent events it covers**. Under independence of events,

  P(fail) = 1 − (1 − ε)^{n_eff}.

Element class: n_eff = n (failure grows with read scope; Law 1). Time class: n_eff ≈ ⌈duration / correlation time⌉;
for operations shorter than one window, n_eff = 1 and failure is flat in n (SQLite). **Classification rule:** a host is
element-class if the failure of a two-element operation exceeds the failure of a one-element operation by at least
half of ε; otherwise time-class.

## 6. Law 2 (blind operation)

Let a blind operation send its structure (keys) as one message to the data's host and receive one reply. If the
message channel fails with probability μ per message, P_blind(fail) = 1 − (1 − μ)² for every n, independent of n.
Blind beats pulling when 1 − (1 − μ)² < 1 − (1 − ε)^{n_eff}, i.e. for n_eff > 2 log(1 − μ)/log(1 − ε). With μ = ε,
blind wins from n_eff ≥ 3 and ties at 2 (OPS1: network 4.03 % vs 2.38 % at n = 1, wins from two keys).

## 7. Law 5 (relations raise the limit)

Let a world have entropy H(W) bits, and let the relations R between its components be known to the reader. Then the
information a perfect reader needs is H(W | R) ≤ H(W). For the T5 network: H(W) ≈ 945 bits, the ideal compressed
length under R ≈ 748 bits. Any store that keeps at least H(W | R) bits of surviving information can in principle be
read completely; a reader that ignores R needs H(W). Relations therefore move the reading limit by H(W) − H(W | R)
bits; a soft joint reader approaches this limit gradually rather than at a cliff.

## 8. Zoom invariance (definition of the fixed point)

A law L(H, o) is **zoom-invariant** on a nested system if it holds with the same form at every level: L(H, o) ⇒
L(z(H), o^z). Theorem 1 is zoom-invariant whenever positive association is preserved by aggregation (it is, for
increasing functions of positively associated variables). Prediction for SPHERE1: the bound holds at the levels fact,
node and sphere.

## 9. Cross-node relations

If node B holds exact knowledge of a subset K of the facts of node A, then reading A with K known removes their
contribution to the interference of every other fact: the variance term of §4's reading falls by Σ_{k∈K} w_k² per
point, so the remaining facts are read with a higher signal-to-noise ratio. Prediction for SPHERE1: facts **not**
supplied by B improve.
