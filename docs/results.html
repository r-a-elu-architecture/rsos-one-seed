What changed and what limits it. A normal agent pipeline needs one model round trip per request, because each request reads what the last one wrote. Once the model writes a program the runtime executes, that dependency moves to the runtime, and the cost stops growing with the number of steps. The remaining bill is the model's thinking: 78–79% of the assembly line's cost is output, 86–87% of it thinking. Against our own earlier runs the cost per task fell about 12×; about 2.4× of that is the harness fix anyone can make.

What followed

Typing was the bottleneck, so an RSOS keyboard layer was built: one key or chord emits a whole component or operator. An automated check keyed 12 targets and decoded them blind from the code alone: 12/12 after one bug fix, 88 of 89 fields recovered (0.989). HT2 runs after a learning phase with a pre-registered plateau gate.

Limits

  • One model family (Haiku-class, one provider). The cross-family test is open.
  • 8–16 tasks per arm: integrity and token differences are large; success differences of one or two tasks are not established.
  • One task family: structured state editing. Free-text collaboration is untested.
  • Competitors are re-implemented from public descriptions; our lossless quantiser favours D.
  • The zero-token heal assumes a second, untouched copy; with both corrupted it costs 18.5 tokens per drift (offline).
  • A2 and A3b each used one engine design call, so the variance between calls is unmeasured.
  • Human evidence: one person, the inventor. No effect on people has been shown.
  • Three of five ledger instruments tested did not track their claims and are being rebuilt.
