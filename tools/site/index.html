Where the operations come from

Core's operations were first written in the RSOS language, a spatial-symbolic notation in which the same programs can be composed. Both forms compile to the same IR, and each Core operation keeps a record of the notation it came from. An operation enters Core only once it is implemented, tested and backed by a pre-registered experiment.

Run it

Python 3.10 or later. Core itself uses only the standard library; the package adds the MCP server. Use it as a library, or add it to any MCP client (Claude Code, Cursor and others) with one command.

State Runtime guideReproduce the results 
# install
pip install rsoslang              # 0.4.0: Core 1.0
claude mcp add rsos -- rsoslang mcp

# use
from rsoslang.core import Ledger
led = Ledger({"auth.owner": "bruno", "search.owner": "bruno"})
led.apply("REHOST owner bruno chen")   # or Core syntax via parse_core
led.dot                                # the state digest
led.sync(agent_copy)                   # repairs drift, 0 model calls
