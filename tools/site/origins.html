Origins

RSOS began as a symbolic language for healing, transforming, signalling and evolving: programs composed as scenes of symbols, flows, beams and colours, run on a host that decides how they behave. Core is the technical layer that grew from it. Every Core operation keeps a record of the symbol it came from.

Three layers

Each layer is useful on its own, and each depends only on the layer below it.

Status ladder

Every element of the language carries one status. Only the last two reach Core, and only with evidence.

  1. Proposed. Named and described.
  2. Specified. Precise meaning, inputs, outputs and errors.
  3. Implemented. Code exists.
  4. Tested. Conformance tests pass.
  5. Executed. Used by real agents in a pre-registered experiment, with published results.
