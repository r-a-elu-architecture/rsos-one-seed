Reproduce

./reproduce.sh runs the test suite and reruns the simulation experiments. The agent experiments are re-analysed from their recorded runs, with no new model calls. Each results file carries a SHA-256 hash of its numbers, so a re-analysis either matches the published hash or shows where it differs.

cd experiments
python3 a1_analyse.py    # A1  → d224abbf…
python3 a2_analyse.py    # A2  → 8916f4de…
python3 a3_analyse.py    # A3  → ff058345…
python3 a3b_analyse.py   # A3b → 0ae0d031… (needs tiktoken)
python3 ht1_score.py     # HT1 → e1f8266b…

The A3b analysis needs tiktoken (o200k). Without it, the analysis stops instead of reporting BPE counts of −1.

What changed from v1 to v2

  • v1 described the language and fixed the predictions of the first real-host test.
  • v2 reports that test (A1) and three more (A2, A3, A3b), plus the first human test (HT1).
  • Comparison now includes re-implementations of two published compact protocols.
  • The keyboard layer, the failure map and the 24-domain programme are new.

Related work

Compact agent messaging is an active field. Each system below optimises one axis: size, structure or term meaning. A3 and A3b measure the one they leave open: whether every copy of the shared state stays true, and what it costs to make it true again.
